# 欢迎来到我的博客

这是我的第一篇博客文章，介绍一下这个博客。

## 关于这个博客

这个博客使用 [Astro](https://astro.build/) 构建，托管在 GitHub Pages 上。

### 技术栈

- **Astro** - 现代静态站点生成器
- **Markdown** - 文章内容格式
- **TypeScript** - 类型安全
- **GitHub Pages** - 静态托管

## 分支说明

- `develop` - 源代码分支
- `blog` - 编译后的静态文件分支

## 写作

在 `src/content/posts/` 目录下创建 Markdown 文件即可开始写作。

```bash
npm run dev  # 本地开发
npm run build  # 构建生产版本
```

祝阅读愉快！🎉
